## Why OpenSearch?

OpenSearch democratizes enterprise search and analytics. You don't need expensive proprietary solutions—you can build scalable, powerful search applications with an **open-source tool**.

- Basic understanding of databases or search concepts
- Docker installed (optional, for the hands-on section)
- Curiosity about search technology! 🔍
